Hello there (or myself :]), this is my personal project on creating a robotic manipulator

#  What is this about?
The objective in this project is to build a small robotic manipulator with the objective of understanding what designers take in count whenever the design one for the manufacturing floor.

What makes this different than others? Rather than look tutorials on Youtube on how to do a simple X-DoF Robotic Arm, I've decided to tackle all the design myself for two reasons
1.  I believe a better understanding on what needs to be considered to be able to build one capable based on manufacturing rather than hobby-like mentality.
2.  Something that I really despise many tutorials is the wiring route, I'm really not a fan how every actuator, controller, and electrical modules are just floating from one location to another. Instead, I want to design it to look simple on the outside.
3.  I wanted to get more involved with feedback control loops and the math behind it. Simply because I think having real hardware can provide a better example for tuning stuff.
